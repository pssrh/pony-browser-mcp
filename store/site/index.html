Pony Browser MCP
Privacy

Local Chrome control for MCP agents

Use your existing Chrome profile while keeping concurrent agent tasks in dedicated windows and named tab groups. Browser traffic stays on the machine through a loopback-only bridge.

Get the release View source

Runs with Codex

Install the companion server from a pinned GitHub release with npm install --global, then add it with codex mcp add pony-browser -- pony-browser-mcp. Managed Chrome policy keeps the signed extension updated without a store listing.

Managed distribution

Use the included policy scripts for macOS, Windows, or Linux. They install the extension once through Chrome policy and follow the HTTPS update manifest on GitHub Pages. See the enterprise guide for commands and verification.

Built for concurrent work

Each task can use a stable workspace, a dedicated browser window, and explicit cleanup. Human review prompts remain visible for credentials, two-factor authentication, and other sensitive steps.

No hosted relay

The extension discovers the local MCP server on 127.0.0.1. It contains no advertising, analytics, or PonyT-operated data service.
