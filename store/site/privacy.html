Pony Browser MCP

Privacy Policy

Effective September 7, 2026

Pony Browser MCP connects Chrome to a companion MCP server selected and run by the user. The extension has no PonyT-operated backend, advertising, analytics, or telemetry.

Data the extension can handle

When the user or their MCP client requests an action, the extension can handle website content, tab and navigation details, screenshots, form values, clipboard content, local storage, and cookies. These categories are required to provide browser automation and are processed only for the requested operation.

How data moves

The extension communicates with the companion MCP server only through WebSocket connections to 127.0.0.1. It does not send browser data to a PonyT server. The MCP client may send tool results to the model provider configured by the user; that transfer is controlled by the MCP client and is covered by the provider's privacy terms.

Storage and retention

The extension stores connection state, task workspaces, and a short local action log in Chrome extension storage. It does not create a remote profile or retain browser content on developer-operated infrastructure. Removing the extension removes its Chrome-managed local storage.

Sharing and sale

PonyT does not collect, sell, rent, or share extension user data. The extension does not use browser data for advertising, credit decisions, or purposes unrelated to its browser-control function.

Permissions

Broad page, cookie, scripting, tab, clipboard, and optional debugger access is necessary because the extension operates websites chosen by the user. Debugger access is disabled by default and is used only when a user request requires the fallback. Storage, alarms, offscreen, notification, and navigation permissions maintain the local bridge and task state.

Security

The companion server binds to loopback only. Software already running on the same computer may be able to reach local services, so users should run only trusted MCP clients and disable the extension when browser automation is not wanted.

Open source and contact
